# OpenComputers 26.2 Port

The modern port is being migrated subsystem-by-subsystem for Minecraft 26.2 / NeoForge 26.2.x / Java 25.

Current foundation includes the computer block/entity, persistent state, component API, hardware model, virtual filesystem and embedded Lua 5.3 runtime boundary.

Remaining milestones: full Lua component bindings, OpenOS-style APIs, EEPROM/HDD persistence, terminal/GUI, screen/keyboard, energy/network adapters, robots, recipes/data generation, rendering and comprehensive GameTests.

The original 1.7.10 source is retained as historical reference and is not compiled unchanged.
