# OpenComputers modern port

The original MightyPirates OpenComputers MC1.12 source is retained unchanged under `OpenComputers/upstream-mc1.12` as the exact reference implementation.

Active target: Minecraft 26.2 (latest stable Java release), NeoForge 26.2.0.62, Java 25.

Minecraft 26.3 is currently a pre-release, so the stable target remains 26.2.
